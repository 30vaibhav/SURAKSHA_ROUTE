Suraksha Route is a women safety system that provides smart, real-time protection during travel by combining live GPS tracking, safe route monitoring, and instant emergency alerts. The system detects route deviations, unusual stops, or any danger and immediately sends an SOS message with the user's live location to trusted contacts using Twilio. It also includes an AI-powered safety chatbot and nearby safe location suggestions to ensure timely help. Suraksha Route is designed to give women confidence while traveling and provide peace of mind to their families.

📌 Key Points
Live Location Tracking – Continuously monitors user movement in real-time.

Safe Route Monitoring – Detects if the user goes off the safe path.

Emergency SMS Alerts (Twilio) – Sends instant SOS messages with live location.

SOS Button – Manual panic alert to notify guardians immediately.

AI Safety Chatbot – Provides guidance, quick help, and safety tips.

Nearby Safe Places – Shows nearest police stations, hospitals, and safe spots.

Secure Authentication – User login and data protection.
